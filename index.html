Guide d'utilisation

Générer un brief en 4 étapes

Aucune installation requise. Ouvrez brief-journalier.html dans votre navigateur et suivez ces étapes.

1
Chargez le PDF Performances Globales
Exporté depuis Darwin → Reporting Magasin. Contient le CA, la marge, les écarts budget, les stocks négatifs et les ruptures.
Obligatoire
2
Chargez le PDF Classement Rayons
Exporté depuis Darwin → Classement Rayons. Fournit le rang CA national et l'évolution de rang de chaque rayon.
Obligatoire
3
Chargez le PDF Comparaison Magasins (optionnel)
Exporté depuis Darwin → Comparaison Magasins pour le rayon souhaité. Active le bouton Classement Région DTF SUD EST.
Optionnel
4
Sélectionnez le rayon et cliquez Générer
Choisissez le rayon dans la liste déroulante. Le brief s'affiche instantanément avec les KPIs, consignes, points d'attention et classement.
Ctrl+S pour sauvegarder la journée

Les 3 exports PDF requis

Tous issus de Darwin, export PDF journalier pour le magasin HF7152 — Narbonne.

📄
Performances_Globales_JJ.pdf
CA TTC, évolution N-1, écart budget, taux marge, diff marge, stocks négatifs, ruptures assortiment — tous rayons.
Obligatoire
📊
CLASSEMENT_RAYONS_JJ.pdf
Rang CA national et évolution de rang pour chaque rayon du magasin. Permet d'afficher le classement national dans le brief.
Obligatoire
🌍
COMPARAISON_MAGASINS_JJ.pdf
Classement des 31 magasins DTF SUD EST sur un rayon spécifique. Active le tableau régional dans le brief. Un PDF = un rayon.
Optionnel
⚠ Note : Le PDF Comparaison Magasins est spécifique à un seul rayon (ex: Confort de la Maison). Pour activer le Classement Région, vous devez sélectionner le même rayon dans la liste déroulante. Le système détecte automatiquement le rayon du PDF chargé.
